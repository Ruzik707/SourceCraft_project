# SourceCraft Repo Health

Веб-сервис оценки здоровья открытых репозиториев SourceCraft: Repo Health Score от 0 до
100 по шести категориям, объяснение оценки до конкретных фактов и приоритизированные
рекомендации по улучшению проекта.

Проанализировано **27 761 репозиторий** каталога. Медианный Score — 52 из 100, лицензия
есть у 8% проектов, настроенный CI — у 23%.

## Что умеет

- **Рейтинг** открытых репозиториев с фильтрами по языку, полноте данных, наличию CI и
  статусу Security; сортировки по Score, лайкам и активности.
- **Страница анализа**: итоговая оценка, разбивка по шести категориям, раскрытие каждой
  до метрик и источников данных, сильные и слабые стороны, сведения о том, чего собрать
  не удалось.
- **Рекомендации** с приоритетом, доказательствами и ожидаемым эффектом на Score.
- **Личный кабинет**: вход через Я ID, свои репозитории, запуск анализа и повторный
  запуск с разницей оценки.
- **Выгрузка отчёта** в Markdown и PDF.
- **Сравнение** до четырёх проектов и **страница методики** прямо в интерфейсе.
- **Периодический пересчёт** по расписанию с историей оценок.

## Быстрый старт

```bash
uv sync
cp .env.example .env
uv run uvicorn main:app --port 8000      # API на :8000

cd frontend
npm ci
cp .env.example .env
npm run dev                              # интерфейс на :5173
```

Подробная инструкция, переменные окружения, развёртывание стенда и разбор типичных
проблем — в [`docs/build-and-run.md`](./docs/build-and-run.md).


## Пользовательский путь

1. Открыть рейтинг, отфильтровать по языку и полноте данных, отсортировать по Score.
2. Перейти в репозиторий: оценка, категории, подтверждающие факты, рекомендации.
3. Выгрузить отчёт в Markdown или PDF.
4. Войти через Я ID, выбрать собственный репозиторий, запустить анализ.
5. После исправлений запустить повторно и увидеть разницу оценки.

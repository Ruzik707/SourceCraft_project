# Примеры результатов

Материалы промежуточной сдачи: как выглядит результат работы сервиса на реальных
репозиториях SourceCraft. Всё в этой папке сгенерировано работающим сервисом, а не
собрано вручную.

Каждый отчёт содержит итоговую оценку, таблицу категорий с весами и статусами,
раскрытие формулы, сильные и слабые стороны, приоритизированные рекомендации с фактами,
сведения об отсутствии данных, ошибки сбора и дату анализа.

## Что стоит заметить в примерах

**Отсутствие данных не портит оценку.** Во всех отчётах категория Security имеет статус
«нет данных»: AppSec отвечает отказом без прав на репозиторий. Категория исключена из
расчёта, полнота данных показана рядом с оценкой.

**Сумма вкладов сходится с итогом.** В таблице «Как получилась оценка» сумма
произведений «оценка × вес» равна итоговому Score — расчёт можно проверить глазами.

**Закрытые репозитории защищены.** Отчёт по приватному `lct-hackaton-2026/case-18-…`
в эту папку не попал: сервис возвращает 404 всем, кроме владельца.

## Как воспроизвести

```bash
./run.sh

# отчёт в Markdown — из интерфейса (http://localhost:5173) кнопкой «Выгрузить отчёт»
# или напрямую из API:
curl -s http://localhost:8000/api/v1/repos/userver/userver | jq .
```

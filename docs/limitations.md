# Ограничения решения

Что сервис умеет, чего не умеет и почему. Документ честный: часть ограничений — свойства
платформы, часть — наши нерешённые вопросы.

## Соответствие программным требованиям (раздел 9.2 ТЗ)

| Требование | Состояние |
| --- | --- |
| Веб-сервис | Интерфейс на React за nginx, REST API на FastAPI |
| Работа с API SourceCraft | Платформенный API, AppSec API, организации и репозитории пользователя |
| Работа с CLI SourceCraft | Реализован запасной путь через `src api <path>`, **но ни разу не отработал** — см. ниже |

## Ограничения платформы

**Данные AppSec доступны у одного репозитория из 27 761.** Платформа отвечает 403 на
запросы результатов SAST, SCA и secret scanning без прав на репозиторий. Поэтому
категория Security почти везде имеет статус «нет данных» и исключается из расчёта.
Это обработано по всему пути — от расчёта до интерфейса и отчёта, — но полноценно
показать Security можно только на репозитории, где сканирование включено владельцем.

**История прогонов пайплайнов доступна у двух репозиториев.** CI/CD оценивается по
конфигурации, категория помечается как «собрано частично» с указанием доли сигналов.

**CLI платформы ни разу не использовался.** В `collector/src/collector/platform_client.py`
реализован запасной путь через `src api <path>`, он срабатывает, когда REST отвечает
ошибкой. Но бинарь `src` не установлен, поэтому во всех 27 761 записях стоит
`platform_cli=false`, а в ошибках — `CLI fallback also failed: src CLI is not on PATH`.
Чтобы закрыть требование ТЗ, нужно поставить CLI и пересобрать часть репозиториев.

**Полный обход каталога занимает дни.** Медиана сбора одного репозитория — 11,5 секунды,
среднее — 63 секунды, максимум в выборке — 9,6 часа. Последовательный обход всех
27 761 репозитория занял бы около 489 часов, при четырёх параллельных сборах — около
пяти суток. Поэтому обход идёт порциями с приоритетом самых старых записей, а не
«полный пересчёт раз в сутки».

## Нерешённые вопросы методики

**Категории без собранных данных считаются по нейтральным значениям.** Из знаменателя
исключаются только `security` и `cicd`, когда сборщик пометил их как недоступные.
Остальные четыре категории всегда участвуют в расчёте, поэтому при неудачном
клонировании документация и активность получают баллы, не подтверждённые данными.
Пример: у `gravity-ui/aikit` рабочая копия не получена, но документация оценена в 8/100,
а активность — в 28/100.

Бэкенд ничего здесь не меняет: отдаёт то, что посчитала методика, а интерфейс помечает
такие категории как «собрано частично» с пояснением «методика учитывает категорию по
нейтральным значениям». Решение за автором методики: либо расширить исключение на все
шесть категорий, либо обосновать текущее поведение. Первый вариант ближе к требованию
ТЗ «отсутствие данных нельзя автоматически трактовать как плохой результат».

**Оценка описывает инженерную гигиену, а не ценность проекта.** Учебный репозиторий с
README, лицензией и CI наберёт больше, чем сложная библиотека без документации.

## Ограничения реализации

**История Score начинается с первого пересчёта.** До второго планового запуска у
репозитория одна точка, и интерфейс пишет об этом вместо пустого графика.

**PDF формируется печатью браузера.** Вид зависит от браузера пользователя. Markdown
собирается в интерфейсе и одинаков везде. Серверная выгрузка файлов не реализована.

**Badge для README не реализован.** Кнопка копирует готовый Markdown, но сам SVG должен
отдавать бэкенд — ручки пока нет.

**Демо-вход.** Для стенда есть `?demo=1`, выдающий сессию без Яндекса. Работает только
при `ALLOW_DEMO_AUTH=true`; на публичном стенде переменную обязательно выключить.

**Запасной токен платформы.** `SOURCECRAFT_TOKEN` в настройках сервиса используется,
когда у сессии нет своего токена. Удобно для демонстрации, но в продакшене так нельзя:
каждый вошедший увидит репозитории владельца токена. Тоже привязано к `ALLOW_DEMO_AUTH`.

## Что нужно, чтобы закрыть оставшееся

1. Установить `src` CLI и пересобрать часть репозиториев — закрывает требование о работе
   с CLI платформы.
2. Получить доступ к AppSec хотя бы для одного репозитория — закрывает демонстрацию
   категории Security.
3. Решить вопрос с нейтральными значениями в методике.
4. Добавить ручку badge и серверную выгрузку PDF — обе относятся к части со звёздочкой.
